# PHỐ AI ECOSYSTEM CORE 2.7 — AI KNOWLEDGE BRAIN

## Mục tiêu
CORE 2.7 biến ứng dụng từ Social Command Center thành hệ thống có "trí nhớ vận hành":
- nhập tri thức từ file .txt / nội dung ChatGPT;
- chia nhỏ dữ liệu và tìm đúng đoạn liên quan;
- Memory Engine ghi nhớ phong cách và kinh nghiệm;
- AI Advisor chỉ gửi các nguồn phù hợp cho OpenAI để tiết kiệm token;
- Content Studio tái sử dụng tri thức và bộ nhớ.

## Module mới
1. AI Knowledge Vault
2. Memory Engine
3. AI Advisor
4. Retrieval Engine cục bộ
5. Backup JSON
6. Supabase schema tùy chọn cho cloud sync

## Quan trọng
- Đây KHÔNG phải huấn luyện lại mô hình OpenAI.
- "Càng dùng càng hiểu" nhờ tri thức, bộ nhớ và kinh nghiệm được tích lũy.
- File .txt được chia nhỏ trước khi tìm kiếm.
- AI Advisor chỉ nhận tối đa các mảnh tri thức phù hợp nhất.

## Không thay đổi
- Facebook OAuth
- Supabase hiện tại
- OpenAI API key
- Redirect URI Meta
- Netlify Functions đang hoạt động
